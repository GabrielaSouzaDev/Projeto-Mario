# 📺 Projeto Mario

## 📌 Sobre o Projeto
O Projeto Mario é uma recriação interativa de elementos inspirados no filme que será lançado do Mario Bros, usando apenas HTML, CSS e JavaScript. Ele apresenta animações e lógica básica de movimentação para trazer uma experiência visual divertida, além de demonstrar manipulação de eventos e controle de elementos na tela.
---
## 🖥️ Demonstração
### 🔗 Acesse o projeto:  
https://trailer-mario.vercel.app/
---
## 🖥️ Ambiente
Este projeto roda em navegadores modernos e não exige servidores ou frameworks complexos — basta abrir o arquivo HTML para que a aplicação funcione. A estrutura é leve e adequada para estudos de front-end e experimentos com animações e eventos.
---
## 🎯 Objetivos

Criar visualmente uma página para a vusualização de um trailer do universo do Mario Bros.

Implementar movimento e interações simples com JavaScript.

Praticar manipulação de eventos do teclado e DOM.

Consolidar conceitos básicos de front-end com um toque lúdico.
---
## ⚙️ Tecnologias Utilizadas

HTML — marcação da estrutura da página

CSS — estilização visual e posicionamento dos elementos

JavaScript — lógica de movimentação e manipulação de eventos
---
## 🧠 Lógica usada
O projeto usa JavaScript para capturar eventos do teclado e atualizar a posição dos elementos na tela em tempo real. A lógica se concentra em responder a comandos do usuário (como pressionar teclas).
---
### 🎓 Aprendizados

Como capturar e tratar eventos do teclado em JavaScript

Manipular estilos e posições de elementos dinamicamente

Entender como estruturar animações simples sem bibliotecas externas

Aplicar lógica interativa para tornar elementos estáticos em personagens animados
---
### ⚠️ Aviso
Este projeto é uma experiência lúdica e não representa um site completo nem possui física avançada — seu principal objetivo é educativo, focado em prática de lógica e manipulação da interface web.
